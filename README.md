# andychamberlin.com

Source for [andychamberlin.com](https://andychamberlin.com): a Quarto website published to GitHub
Pages by `.github/workflows/publish.yml` on every push to `main`.

## Layout

```
index.qmd               homepage (banner, service cards, project tiles, media highlights)
projects/<slug>.qmd     one short page per project; files starting with _ are held back
publications.qmd        includes _data/publications.md
media.qmd, contact.qmd
_data/                  generated by export_site_data.py in the private cv repo; don't edit
_includes/jsonld.html   generated by scripts/build_jsonld.py from _data/profile.json
images.yml              source photo -> web image manifest
assets/img/             processed images only (≤2000 px, no EXIF/GPS)
tests/                  pytest checks on scripts and the rendered site
```

## Common jobs

Set up once: `conda env create -f environment.yml`, and install Quarto (≥1.6).

Update publications (in the cv repo, then here):

```bash
python ~/Projects/cv/publications/refresh_publications.py
python ~/Projects/cv/export_site_data.py --site-dir ~/Projects/personal-site
python scripts/build_jsonld.py      # only if profile.json changed
```

Add or swap an image: add an entry (`src`, `out`, `alt`) to `images.yml`, then
`python scripts/prepare_images.py`. To browse candidates first:
`python scripts/contact_sheet.py contact_sheet/sheet <folder or files>` and open
`contact_sheet/sheet/index.html`.

Add a project: copy an existing `projects/*.qmd`, set `title`, `description`, `image`,
`image-alt`, `date`. To hold a page back, prefix the file name with `_`.

Check before pushing: `conda activate personal-site && pytest -q` (renders the site).
Preview: `quarto preview`.
